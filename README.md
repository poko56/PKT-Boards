# PKT Boards

แบบวงจรและ PCB ของทีม [PKT POKOTEAM](https://pktpcb.web.app) ออกแบบด้วย KiCad

| บอร์ด | ขนาด | จุดเด่น | สถานะ |
|---|---|---|---|
| [PKT ESP32 Dev Board](esp32-devboard) | 29 × 54.6 มม. | ESP32-WROOM-32E, USB-C, auto-reset | มี Gerber, ยังไม่ทดสอบบอร์ดจริง |
| [PKT ESP32-C3 Mini](esp32c3-mini) | 20 × 34 มม. | ESP32-C3-MINI-1, USB-C, ไฟสะอาดด้วย LDO | มีไฟล์สั่ง JLCPCB, ยังไม่ทดสอบบอร์ดจริง |
| [PKT ESP32 Robot Arm Controller](esp32-arm-controller) | 80 × 64 มม. | คุม servo 5 แกน, E-stop แบบ fail-safe | ยังเดินลายไม่ครบ, ยังไม่มี Gerber |

> ทุกบอร์ดยังไม่ผ่านการทดสอบกับบอร์ดจริง ตรวจไฟล์ทุกครั้งก่อนสั่งผลิต
